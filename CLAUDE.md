# CLAUDE.md - Terra Light (Starsector mod)

Guide for Claude sessions working on this repository. Maintainer: **Skykyrie** (not a programmer: explain
changes in plain words, one step at a time when they need to do something themselves).

## What this is
Terra Light ports the Union warships of *Earth Light* (SNES, Hudson Soft 1992) into **Starsector 0.98a-RC8**.
15 ships (5 capitals, 7 cruisers, 3 destroyers), custom ship systems, moving parts. No dependencies on other mods.
Unofficial, non-commercial fan work; no copyright claimed (CC0 for our own material, see NOTICE.md).

## Standard workflow for any change
1. Read the relevant ship section in `dev/DESIGN.md`.
2. Change the source (build script, `tl_java/`, a `vs_*.py` sprite script, `tl_desc.py`...).
   New sprite versions: copy `vs_<ship>N.py` to `N+1`, never overwrite an approved version; update the SHIPS table in the build.
3. Build and check:
   ```
   cd dev && python3 build_v11.py && python3 validate_v6.py && bash tools/jcheck.sh
   ```
   `validate_v6.py` must print `ERRORS 0`; `jcheck.sh` must print no `error:` lines.
4. Bump `VERSION` in `build_v11.py` for anything players should download.
5. `python3 dev/tools/sync_to_repo.py` (from the repo root) - updates `data/`, `graphics/`, `mod_info.json` and writes
   `dev/_scratch/TerraLight_vX.Y.Z.zip`.
6. Log the decision in `dev/DESIGN.md` (short section, what + why), commit, open a PR.
7. Tell Skykyrie what changed and that it needs an in-game test (Claude cannot run Starsector).
   After merge, the release zip goes on a new GitHub Release (tag vX.Y.Z).

Python deps: `pip install numpy scipy opencv-python-headless pillow`. Java: any JDK (javac) for jcheck.

## Rules and lessons learned (keep them)
- **Design workflow (maintainer's rule):** new ships get a three.js 3D block-out first (numbered parts, arc sweeps,
  a THRUSTER FLIGHT PREVIEW with idle/forward/strafe/turn buttons), then the 2D sprite once approved.
  Moving parts must be collision-checked across their full motion.
- **Loose Java scripts are compiled by Janino in-game:** no lambdas, no diamond `<>`, don't declare generic types
  (use raw `List` + casts), keep every class self-contained (nested static classes are fine; don't reference
  other loose script classes). Always run `bash tools/jcheck.sh`.
- **Starsector resets weapon/missile sprite alpha every frame.** To hide a sprite, shrink it with `setSize(0,0)` and
  restore the size when drawing it yourself (see `TL_Hull` and `TL_SirenModes`).
- **Under-hull weapons:** slot ids starting `UH` are normal refittable slots; `TL_Hull` hides them and redraws them on
  `UNDER_SHIPS_LAYER`. Overlapping slots can't be clicked in the refit screen - use a module (Hellhound tower).
- **The refit screen also runs hullmod `advanceInCombat`:** anything combat-only must check
  `Global.getCurrentState() == GameState.COMBAT` (sprite swaps broke the refit view once).
- **Launch bays need several launch points** (`locations` with 3 pairs), or fighters launch from the ship centre.
- **Engine flames can't move with parts** - only their angle can change (`EngineSlotAPI.setAngle`).
- All ids use the `tl_` prefix. Vanilla ids must exist in `vanilla_ref.json` (the validator checks).
- Never add Starsector or Earth Light files/text to the repo. Ship descriptions are original wording.
