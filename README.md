# Terra Light

Bringing the Earth Light SNES spaceships and things over to the beloved game Starsector!

15 Union warships from *Earth Light* (Hudson Soft, 1992), redrawn top-down in the Starsector style,
with their own ship systems and moving parts.

- **Capitals:** Tiamat, Asura-II, Neow, Artemis, Siren
- **Cruisers:** Hastur, Hannibal, Regulus, Duilius, Abaddon, Iris, Selene
- **Destroyers:** Fenrir, Hellhound, Garm

## Install

1. Download `TerraLight_vX.Y.Z.zip` from the [Releases](https://github.com/skykyrie/starsector-terralight/releases) page (not the green "Code" button).
2. Unzip it into `Starsector/mods/` so you get `Starsector/mods/TerraLight/mod_info.json`.
3. Tick **Terra Light** in the Starsector launcher.

Requires Starsector 0.98a-RC8. No other mods needed.

## Ship systems

| Ship | System | Effect |
|---|---|---|
| Tiamat | Triple Overcharge | energy weapons fire twice as fast for half the flux |
| Asura-II | Rail Overdrive | ballistic rate of fire x2, half flux, speed surge |
| Neow | Damper Field + Flare Screen (right-click) | no shield; flares from 8 tubes all round |
| Artemis / Iris | Reserve Deployment | vanilla |
| Siren | Battleship Mode | toggle: carrier (guns folded) / battleship (guns up, fighter replacement paused) |
| Hastur | Replica Wing | every wing launches a full replica set for 20 s |
| Hannibal | AP Focus | energy +60% damage, +30% range, +50% vs capitals |
| Regulus | Screen Overdrive | x2 vs fighters/missiles, +50% vs destroyers |
| Duilius | Claw Strike | 8 grapple claws that ignore shields |
| Abaddon | Apocalypse | once per battle; needs a locked target; huge blast |
| Selene | Wing Rally | repairs and boosts its fighters |
| Fenrir | Hit and Run | speed and agility burst |
| Hellhound | Execution Salvo | rapid fire, bonus hull damage, missiles reloaded |
| Garm | Phase Skimmer | vanilla |
